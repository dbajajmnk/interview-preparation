# Week 1: Light DSA Practice

This folder contains easy-level Data Structures and Algorithms problems to get started with DSA practice in TypeScript.

## Files

- `arrays-easy.ts` - Basic array manipulation problems
- `strings-easy.ts` - String processing problems
- `hash-maps-basic.ts` - Introduction to Maps and Sets

## Problems Included

### Arrays (arrays-easy.ts)
1. Find Maximum Element
2. Find Minimum Element
3. Calculate Sum
4. Calculate Average
5. Reverse Array
6. Reverse Array In-Place
7. Find Element
8. Count Occurrences

### Strings (strings-easy.ts)
1. Reverse a String
2. Check if Palindrome
3. Count Vowels
4. Count Words
5. Capitalize Words
6. Remove Duplicates
7. Check Anagrams
8. Find Longest Word

### Hash Maps/Sets (hash-maps-basic.ts)
1. Two Sum
2. Find First Duplicate
3. Count Character Frequencies
4. Group Anagrams
5. Contains Duplicate
6. Find Missing Number
7. Intersection of Two Arrays

## How to Run

Each file can be run independently:

```bash
# Using ts-node (if installed)
ts-node DSA/week1/arrays-easy.ts

# Or compile first
tsc DSA/week1/arrays-easy.ts
node DSA/week1/arrays-easy.js
```

## Practice Tips

1. **Read the problem** carefully and understand what's being asked
2. **Think about edge cases** (empty arrays, single element, etc.)
3. **Write the solution** with proper TypeScript types
4. **Analyze complexity** - always note time and space complexity
5. **Test your solution** with the provided test cases and add your own
6. **Try to optimize** - can you improve time or space complexity?
