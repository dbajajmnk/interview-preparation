# DSA Practice in TypeScript

This folder contains Data Structures and Algorithms practice problems solved in TypeScript.

## Structure

- `data-structures/` - Core data structure implementations
- `week1/` - Easy problems for Week 1 (arrays, strings, basic patterns)
- `week2/` - Slightly harder problems (hash maps, two pointers)

## Practice Routine

- 1–2 problems per weekday
- 3–4 problems on weekends
- Always analyze time & space complexity
- Test your solutions with multiple test cases
